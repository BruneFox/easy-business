# Easy Business

Backend of a text-based economic game: players buy businesses, stock up their warehouses,
sell products and upgrade levels. Includes roles (player / admin) and admin actions.

**Stack:** FastAPI, SQLAlchemy (async), PostgreSQL, Alembic, JWT, Docker, pytest

## Features

- Registration and login (JWT), roles Player / Admin (the first registered user becomes an admin)
- Businesses: create, restock the warehouse, sell products, upgrade up to level 15
- Production is calculated from the time since the last update (no background jobs)
- Admin: list users, ban, give money and roles
- REST-style API with Swagger documentation at `/docs`

## Quick start

```bash
git clone https://github.com/BruneFox/easy-business
cd easy-business
cp .env.example .env
docker compose up --build
```

Once it is running:

- App: http://127.0.0.1:8000
- API docs: http://127.0.0.1:8000/docs

## Tests

```bash
pip install -r requirements.txt -r tests/requirements-dev.txt
pytest tests/ -v
```
